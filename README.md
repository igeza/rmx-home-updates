# Home updates — RMX prototype

How Homes (manufactured housing) show up across Rent Manager Express, from a vacant lot to a new tenant.

**Open the prototype:** https://igeza.github.io/rmx-home-updates/ — it starts on Unit detail (Lot 101).

Demo flow: Unit detail → Mega Menu › Homes → Mega Menu › Prospects → Charlie Apegian → Move In → Move In in the wizard → Tenant detail.

Built with the `rmx-prototyping` skill. See `PROTOTYPE.md` for what each screen shows, what is faked, and deliberate deviations from the design system.
